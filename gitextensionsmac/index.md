<p class="gem-meta" markdown="0">
  Revision graph, commits, branches, remotes, stashes, rebase, cherry-pick, bisect, blame, file history, and an embedded terminal, built with Swift and AppKit. It drives the real <code>git</code> executable, so your existing config, SSH keys, and credential helpers keep working. The terminal installer installs GitExtensionsMac in Applications and removes macOS quarantine. GitExtensionsMac remains unsigned and unnotarized. It is an independent port and is not affiliated with the Git Extensions team. <a href="https://github.com/norgera/GitExtensionsMac">View the source on GitHub</a>.
</p>
