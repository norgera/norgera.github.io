# GitExtensionsMac Privacy Policy

**Effective November 10, 2026**

GitExtensionsMac does not collect, transmit, sell, or share personal information with the developer. It has no accounts, analytics, advertising, telemetry, or cloud service.

## Local data

GitExtensionsMac stores its settings, recent repositories, and caches locally on your Mac. If you add a GitHub personal access token, it is stored in the macOS Keychain and is only sent to GitHub.

## Network connections

The app only connects to services you use or configure:

- **Git operations.** Fetch, pull, push, and clone are performed by the `git` executable on your Mac and connect only to the remotes you configure.
- **Avatars.** Avatars are off by default. If you turn them on, the app requests commit author images from Gravatar (using a hash of the author's email address) and from GitHub.
- **Integrations.** If you set up the GitHub integration or a build server such as Jenkins or Azure DevOps, the app connects to that service with the address and credentials you provide.

Those services handle requests under their own privacy policies.

## Error reports

Error reports are never sent automatically. When an error occurs, the app can open a pre-filled GitHub issue in your browser, which you can review and choose whether to submit. GitHub issues are public.

## Website and support

The GitExtensionsMac pages do not use analytics or tracking scripts. This site, downloads, and the project repository are hosted by GitHub, which may process basic request information under its [Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).

If you open an issue or send an email, any information you provide is used only to respond or maintain GitExtensionsMac.
